# Application Landscape Migration Advisor

This repository contains the project principles and general requirements for an
advisory application that assesses how an existing application fits into a wider
technology landscape. It covers capability mapping, migration options,
decommission readiness, and a staged transition roadmap.

The work is at the specification stage. No application implementation is included.

- [Project constitution](.specify/memory/constitution.md)
- [Feature specification](specs/002-assess-application-fit/spec.md)
- [Requirements quality checklist](specs/002-assess-application-fit/checklists/requirements.md)

The `.specify/` and `.agents/skills/` directories contain the Spec Kit workflow
used to continue planning and development.
