# Application Landscape Migration Advisor

This repository contains the project principles and general requirements for an
advisory application that assesses how an existing application fits into a wider
technology landscape. It covers capability mapping, migration options,
decommission readiness, and a staged transition roadmap.

The work is at the specification and design stage. No application implementation
is included.
